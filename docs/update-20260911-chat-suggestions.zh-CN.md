# 2026-09-11：原生聊天建议支持最多 7 个选项

版本：1.2.6+74（Android Release）。

## 修改内容与原理

- 原生聊天建议解析上限从 3 条增加到 7 条。
- 气泡界面复用解析服务的同一个数量常量，消除界面单独截取 3 条的限制。
- 返回 6 条显示 6 条，返回 7 条显示 7 条，超过 7 条截断；不自动补齐。
- 保留去空白、去重、编号清理和单条 300 字符限制。
- 不修改用户已保存的自定义提示词。默认提示词仍可能要求 3 条，需要自定义要求 6～7 条。

## 使用方法

启用原生聊天建议并选择建议模型，在建议提示词中要求生成 6～7 个行动，每行一个，不附标题、解释或代码围栏。停用此前用于正文内生成选项的行动选项世界书，以免两套方案同时运行。

建议仍通过独立 API 请求生成，默认读取最近最多 8 条消息、合计末尾 4000 字符；本次未扩大上下文，也不自动注入主聊天的完整世界书和预设。
